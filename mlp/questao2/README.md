# Questão 2 — MLP (classificação de qualidade de vinhos)

Wine Quality Dataset (UCI, id 186). Classes: baixa (notas 0–4), média (5–6), alta (7–10).

Entregar: análise exploratória, pré-processamento (valores ausentes, atributos redundantes, normalização, distribuição das classes),
avaliação de técnicas de balanceamento, arquitetura, curvas de treino e validação, matriz de confusão, accuracy, precision, recall e f1-score.
